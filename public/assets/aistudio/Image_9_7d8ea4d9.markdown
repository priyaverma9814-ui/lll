## Brand & Style

This design system delivers an intuitive, deep-engineering environment built to transition novices into rigorous systems thinkers. It captures the atmosphere of a high-end IDE, mission-control console, and interactive systems workbench. 

### Aesthetic Philosophy
- **Dark Engineering Precision:** A focused, distraction-free environment anchored in slate-950 obsidian depths. Surfaces feel engineered rather than decorated, using low-reflectance charcoal and zinc planes punctuated by high-signal luminescent telemetry.
- **Cybernetic Tactility:** Interactive modules emulate specialized laboratory instrumentation: modular docking tiles, subtle glowing bus lines, interactive scrubbers, and live diagnostic readouts.
- **Cognitive Clarity:** The UI rejects superficial visual noise in favor of semantic signal density. Complex abstractions are decomposed into clear, inspectable mechanical mental models.

### Target Audience & Tone
- **Audience:** Aspiring infrastructure engineers, systems programmers, and technical builders transitioning from syntax memorization to structural computational thinking.
- **Tone:** Authoritative, razor-sharp, intellectually empowering, and calm under high cognitive load.

## Colors

The palette employs deep dark-matter foundations layered with high-contrast, luminescent semantic accents. Every hue carries strict functional meaning across conceptual, mechanical, and diagnostic boundaries.

### Core Canvas & Surfaces
- **Canvas (`#0b0f17`):** The primary void. An ultra-deep slate-black base that eliminates eye strain and heightens luminescent signals.
- **Card Surface (`#141a24`):** Elevated modular component planes, providing perceptible contrast without glare.
- **Subtle Structural Border (`#232d3f`):** Precision division lines, maintaining clean visual boundaries across modular grids.
- **Surface Hover / Active (`#1c2433`):** Micro-elevated state for interactive modules and selected panels.

### Semantic Accents & Telemetry
- **Primary Electric Cyan (`#00f2fe`):** Interactive glow, cursor leads, highlighted bus tracks, and forward action anchors. Secondary cyan tone (`#38bdf8`) handles focused borders and active state highlights.
- **Violet Concept (`#8b5cf6`):** Theoretical mental models, structural abstractions, architectural layers, and architectural block highlights.
- **Emerald Pass (`#10b981`):** Verified execution states, passing assertions, compiled binaries, and healthy system telemetry.
- **Amber Triage (`#f59e0b`):** Bottlenecks, memory constraints, triage alerts, and diagnostics requiring runtime intervention.
- **Rose Fault (`#f43f5e`):** Runtime exceptions, deadlocks, and critical failing tests.

## Typography

The typographic hierarchy bridges high-grade modern product design with mechanical source code telemetry.

- **Primary Structure (Plus Jakarta Sans):** Applied to headlines, section headers, and high-level milestones. Provides a clean, modern aesthetic with geometric balance.
- **Narrative & Explanation (Inter):** Applied across core pedagogical text, technical guides, and instructional tooltips. Optimized for sustained readability under low ambient contrast.
- **Telemetry & Computation (JetBrains Mono):** Applied to code blocks, interactive memory scrubbers, system stats, metrics, and pill tags. Features clean tabular figures for numerical alignment.

## Layout & Spacing

The layout is built on a responsive 12-column engineering grid engineered for split-screen reading, real-time code execution, and architectural diagrams.

### Grid & Breakpoints
- **Mobile Viewports (< 768px):** 4-column layout with `1rem` outer margins and `0.75rem` gutters. Stacks interactive workbenches beneath documentation modules. Scrubber controls, execution docks, and telemetry bars anchor to the bottom edge.
- **Tablet / Medium Displays (768px – 1024px):** 8-column layout with `1.5rem` margins and `1rem` gutters. Supports side-by-side terminal logs alongside diagram flowcharts.
- **Desktop (1024px+):** 12-column modular grid with `2.5rem` canvas margins and `1.5rem` gutters. Enables a persistent 3-column architecture: Concept Navigation & Table of Contents (2–3 cols), Interactive Systems Workbench / Code Plane (5–6 cols), and Live Telemetry & Inspector Bar (3–4 cols).

## Elevation & Depth

Visual hierarchy uses tonal surface layering, ultra-fine boundary definition, and calibrated photoluminescent glows.

### Tonal Stratification
- **Floor (`#0b0f17`):** The primary view base.
- **Base Modules (`#141a24`):** Cards, editor surfaces, and execution bays; framed by `#232d3f` 1px borders.
- **Elevated Modals & Popovers (`#1c2433`):** Flyout tooltips, inspection overlays, and modal inspectors; bounded by `#334155` borders.

### Photoluminescent Glow & Ambient Shadows
- **Passive Shadow:** Component cards utilize `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.65)`.
- **Primary Interactive Glow:** Active interactive inputs and focused cards feature a 1px border of `#00f2fe` accompanied by `box-shadow: 0 0 16px -2px rgba(0, 242, 254, 0.25)`.
- **Verified / Success Glow:** Passing states and verified system nodes employ `box-shadow: 0 0 12px -2px rgba(16, 185, 129, 0.3)`.
- **Diagnostic Triage Glow:** Active diagnostic alerts project `box-shadow: 0 0 12px -2px rgba(245, 158, 11, 0.25)`.

## Shapes

The design uses a clean, compact corner radius to project precision machinery and tactical discipline.

- **Primary Cards & Containers (`rounded-base` / `0.25rem`):** Applied to core code blocks, modular canvas panels, execution docks, and inspection panes.
- **Telemetry Badges & Scrubber Knobs (`rounded-lg` / `0.5rem`):** Pill-style status tokens, interactive sliders, and runtime indicator chips.
- **Subtle Border Rule:** Interactive targets always employ a crisp 1px solid stroke (`#232d3f` resting, transitioning to `#00f2fe` or `#38bdf8` on active focus).

## Components

### Buttons
- **Primary Action (Execute / Run Simulation):** Solid electric cyan (`#00f2fe`) fill with deep-slate text (`#0b0f17`, font weight 600). Hover produces an ambient cyan bloom (`0 0 18px rgba(0, 242, 254, 0.45)`).
- **Secondary (Inspect / Step Forward):** Dark background (`#141a24`), 1px border in `#232d3f`, text in `#e2e8f0`. Hover brightens the border to `#38bdf8` with foreground shift to white.
- **Ghost Utility:** Borderless with monospace label in `#94a3b8`, illuminating to `#00f2fe` on interaction.

### Telemetry Badges & Chips
- **Status Pills:** Monospace micro-typography (`label-caps`), 3px inner padding, `0.5rem` corner radius, dark tinted background (`#141a24`), featuring a 6px pulsing circular indicator dot.
  - *Passing:* Emerald dot (`#10b981`) with `#10b981` low-opacity fill (`rgba(16, 185, 129, 0.1)`).
  - *Triage:* Amber dot (`#f59e0b`) with warning amber fill (`rgba(245, 158, 11, 0.12)`).
  - *Theory:* Violet dot (`#8b5cf6`) with abstraction badge fill (`rgba(139, 92, 246, 0.12)`).

### Interactive Memory & Time-Travel Scrubber
- **Track:** 4px height, background `#1e293b`, overlaid with active progress rail in `#00f2fe`.
- **Thumb:** 14px × 14px squared diamond or rounded square (`rounded: 2px`), `#00f2fe` with outer ring glow. Drag states display live frame count or timestamp in `mono-sm` floating tooltip.

### Input Fields & Terminal Consoles
- **Field Base:** `#0e141f` surface, inset stroke `#232d3f`, monospace typography (`mono-md`), placeholder text in `#475569`.
- **Active State:** 1px stroke in `#00f2fe`, soft inward cyan aura.

### Modular Engineering Cards
- **Construction:** Structured with a distinct top metadata bar (`#101622`) housing panel tabs, title, and status badges, separated by a 1px border (`#232d3f`) from the inner workbench body (`#141a24`).
- **Interaction:** Hovering lifts the border to `#334155`; focused states introduce a top-edge 2px accent rule in `#00f2fe`.

### Checkboxes & Toggle Switches
- **Checkboxes:** 16px × 16px squares with 2px corner radius. Inactive: `#141a24` with 1px `#232d3f`. Selected: `#00f2fe` fill with `#0b0f17` check icon.
- **Toggle Switches:** Track dimensions 36px × 18px in `#1e293b`. Thumb: 14px circle moving from `#64748b` (inactive) to `#00f2fe` (active) with dynamic glow.
